# Bytekart

A shopping app built using flutter.

## Pages
- Home
- Wishlist
- Cart
- Profile
- Orders
- Deals
- Trending Products
- Search Products

## Features Implemented
- Adding / removing products to cart
- Wishlisting / unwishlisting a product
